Embedded Chat Popup Example

This page demonstrates how to embed chat-embed.html as a popup widget with preset parameters passed via the query string.

Method 1: Direct iframe (Simple)

  • How to render a floating "Chat with us" button.
  • How to open/close a popup that contains the embeddable chat iframe.
  • How to override RAG parameters via the iframe URL, for example: top_k, max_output_tokens, and show_processing_steps.

This example uses: ?top_k=5&max_output_tokens=256&show_processing_steps=true&show_sources=true&namespace=example-popup in the iframe src. You can change these query parameters to adjust retrieval depth, output length, or whether processing steps are streamed.

Method 2: Embed Loader Script (Flexible)

  • Uses embed-loader.js to dynamically create the iframe.
  • Configuration via data attributes on the script tag.
  • More flexible - script handles iframe creation and sizing.
  • Cleaner HTML - just a div and script tag.

This method uses the same parameters but passed as data attributes: data-top_k="5", data-max_output_tokens="256", data-show_processing_steps="true", data-show_sources="true", data-namespace="example-script"
